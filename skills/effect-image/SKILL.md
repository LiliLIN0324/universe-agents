# 图素材

## 先分清要的是哪种图

| 要什么 | 做法 |
| --- | --- |
| 真实存在的东西（某款产品、某个地方） | 先找现成图片，再决定要不要生成 |
| 还没做出来的东西（未来产品、概念场景） | 生成 |
| 现有图的修改（换背景、改尺寸、去杂物） | 图生图，不要重新生成 |
| 标志、图标、规则的几何图形 | 用矢量工具画，不生成 |

标志绝对不要用生成模型做。同一句话生成两次，得到两个不同的标志，这不叫标志。

## 提示词写法

按这个顺序写，缺哪项补哪项：

```
主体 + 材质/质感 + 光线 + 构图/视角 + 背景 + 用途比例
```

示例：

> 一张浅木色长桌，桌面上放着两副眼镜和一本摊开的笔记本，上午侧光从左侧窗进来，
> 桌面有淡淡的影子，背景是白墙，俯视 45 度，画面留出上方三分之一空白用于放文字，16:9。

要避免的说法：

- 「高级感」「有质感」「电影感」——模型各有各的理解
- 「不要 X」——否定词经常反而把 X 带进来
- 一长串风格标签堆叠——颜色和光线会打架

## 尺寸

- 先定用途，再定尺寸。竖图放进横版页面里，只能裁或留白。
- 同一个项目里所有配图用同一组比例，不要忽横忽竖。
- 生成大图再缩，比生成小图再放大好。

## 落盘

```
assets/<用途>/<名字>-<宽>x<高>.png
```

例：

```
assets/hero/studio-desk-1920x1080.png
assets/avatar/team-lead-512x512.png
```

不要用「未命名 (3)」「final-final」这种名字。生成失败或不要的图，当次就删掉，不要留在目录里。

## 生成后必须看

不能只看缩略图。要按实际使用尺寸看：

1. **手**：手指数量、握持姿势
2. **文字**：生成的文字基本都是错的，需要文字就后期加
3. **边缘**：物体边缘有没有融在一起
4. **光线方向**：同一个场景里两个光源方向，会显得假
5. **颜色**：和项目已有的图放在一起，色调是不是一路

## 一组图要统一

同一组素材，用同一段描述模板，只换主体。记录下那一段模板，下次续做时照抄。

颜色以项目已有的色板为准，不要每组图自己定一套。

## 常见错误

- **拿生成图当真实产品图**：客户会以为是实拍，实物到手不一样，是纠纷。
- **一张图改十遍**：每改一次都会漂移，改到第三遍往往不如第一遍。要么重写提示词，要么换图生图。
- **不留提示词**：两周后要补一张同风格的，找不到怎么做的。
- **不删废图**：素材目录一千张图，没人知道哪张在用。
